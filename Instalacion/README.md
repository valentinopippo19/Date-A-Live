# Instalacion de Date A Live AI

Los scripts de esta carpeta preparan y ejecutan el proyecto desde su **directorio raíz**, un nivel por encima de `Instalacion`.

- `INSTALAR.bat`: instala o repara dependencias.
- `EJECUTAR.bat`: inicia el servidor local y abre el navegador.
- `INICIAR.bat` (raíz): instala si hace falta y después ejecuta.
- `instalar.ps1`: lógica principal de instalación.
- `requirements.txt`: dependencias Python.

No ejecutes los scripts desde una carpeta copiada separadamente: `Instalacion` debe permanecer dentro de `Date-A-Live-main`.
